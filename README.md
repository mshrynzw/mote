# Mote

Windows 11 向けのウェーブテーブル・シンセサイザーです。DAW に読み込ませる形式は VST3 です。

軽い動作を仕様にします。エンジンの上限は同時発音 128、ユニゾン 16 です。
日常の目安として、16 音、オシレーター 4 基、ユニゾン 8 でも 48 kHz で CPU のコアを占有しきらないことを目標にします。

## いまの段階

Phase 1 は、MIDI でサイン波が鳴る VST3 だけです。独自の画面、ユニゾン、フィルター、エンベロープは入れません。
ビルド手順は、音が鳴ってからここに追記します。

Phase 2 以降の範囲、日程、要件、設計の詳細は、Phase 1 が鳴ったあとに [docs/design.md](docs/design.md) の方針どおり `docs` へ足します。

Audio Unit は、Mac が手に入ってから対応します。
