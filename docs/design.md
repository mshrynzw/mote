# Mote の設計

この文書は、最終的な音の姿と、いま実装する Phase 1 を分けて書く。
Phase 2 以降の切り方、日程、要件、設計の詳細は、Phase 1 が DAW で鳴ったあとに、このフォルダへ追記する。先には書かない。

## Phase 1

完了は、次の 4 つが揃ったときとする。

- Cubase 13 か FL Studio に VST3 として読み込める
- MIDI のノートオンで、その音程のサイン波が出る
- ノートオフで音が止まる
- 独自の画面、ユニゾン、フィルター、エンベロープは入れない

発音中にメモリを確保しない、というルールはこの範囲でも守る。ビルド手順は、鳴ったあと `README.md` に追記する。

## 最終的な姿

中心はウェーブテーブル・シンセサイザーにする。音の厚みと軽さは Sylenth1 と Viper、音の広がりと現代的な声数は Serum 2 を方向の参考にする。
画面、波形 ROM、プリセットはコピーしない。ここは未実装である。

声の数には余白を残す。エンジンの上限は、同時発音 128、各オシレーターのユニゾン 16 とし、その分のメモリは起動時に確保する。
日常のパッチで軽く保つ目安は、同時発音 16、オシレーター 4、ユニゾン 8 である。使っていない声は計算しない。上限まで鳴らしたときだけ負荷が増える。

- パート A とパート B。各パートにオシレーター 2 基、フィルター、アンプ
- 各オシレーターのユニゾンは 1〜16。音程のずれ、左右の広がり、定位、音量、リトリガーと位相
- 同時発音は 1〜128
- サブオシレーター、ノイズ、オシレーター間のシンク、FM、リングモジュレーション
- フィルターはゼロディレイ・フィードバックのマルチモード（ローパス、ハイパス、バンドパス、ノッチ）にドライブ
- エンベロープ 4、LFO、モジュレーション・マトリクス
- マスター側にディストーション、フェイザー、コーラス、EQ、ディレイ、リバーブ、コンプレッサー、アルペジエーター

なお、実装過程で最終的な姿の方針が変更する可能性ある。

### オシレーターのモード

出荷する波形は、自前の計算と自作のウェーブテーブルで用意する。
実機の録音は耳の基準と、利用者が自分で読み込む wav に限る。出荷データには入れない。

JP-8000 や Virus のような厚いノコギリは、録音した 1 周期ではなく Stacked Saw の計算で作る。機種名は音の方向の呼び名にとどめ、商品名にはしない。

| モード | 音 |
| --- | --- |
| Classic | サイン、三角、ノコギリ、パルス幅付き矩形 |
| Stacked Saw | 1 基の中でノコギリを最大 9 枚重ねる |
| Wavetable | 自作テーブルと、利用者が読み込む wav |
| Sync / FM / RM | オシレーター間の変調 |
| Sub / Noise | 1 オクターブ下と、色付きノイズ |

ユニゾン（声を複製して左右と音程を広げる）と Stacked Saw（1 基の中でノコギリを重ねる）は別のノブにする。

### ユニゾンの配置図

各オシレーターに、声の位置を描く。これも Phase 1 には入れない。

- 横軸は定位、縦軸はデチューン（セント）
- 1 声が 1 点。音量で大きさが変わる
- わずかな揺らぎで点が動く
- 選んでいる波形を、同じパネルに小さく描く
- Stacked Saw の各ノコギリは、薄い点で重ねる

描画はオーディオスレッドの外で行う。
